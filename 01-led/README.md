# LED Projects

This repository contains a collection of beginner-friendly LED projects created to explore and understand the fundamentals of programming LEDs using an ESP32.

Each project focuses on a different lighting behavior or control technique, helping build a strong foundation in LED control, timing, brightness adjustment, and visual effects before moving on to more advanced electronics and embedded systems projects.

These examples demonstrate concepts such as digital output, PWM brightness control, timing with delays, controlling multiple LEDs, sequencing outputs, creating lighting animations, and generating random patterns. They can also serve as reference implementations that can be reused and expanded in future robotics, IoT, and embedded systems projects.

## Projects Included

### Blinking LED

A basic project that turns an LED on and off repeatedly. This introduces digital output and demonstrates how a microcontroller can control an LED using a GPIO pin.

### Fading LED

Uses PWM (Pulse Width Modulation) to smoothly increase and decrease an LED's brightness. This introduces PWM-based brightness control and demonstrates how digital hardware can be used to create smooth changes in LED brightness.

### Traffic Light

Simulates a real-world traffic light by controlling red, yellow, and green LEDs in a timed sequence. This introduces multi-LED control and state-based timing, demonstrating how a microcontroller can coordinate multiple outputs to follow a specific sequence.

### Heart LED

Creates heart-shaped lighting animations using multiple LEDs. This introduces synchronized LED patterns and visual effects, demonstrating how multiple outputs can be coordinated to create more complex lighting animations.

### Random LED

Randomly selects LEDs to illuminate, creating dynamic lighting patterns and simple animations. This introduces random number generation and demonstrates how programming logic can be used to create unpredictable output behavior.

## Learning Objectives

By completing these projects, you will gain experience with:

* Configuring GPIO pins for LED control
* Writing basic Arduino/ESP32 programs
* Using digital outputs
* Controlling LED brightness with PWM
* Understanding PWM-based brightness control
* Creating timed lighting sequences
* Controlling multiple LEDs
* Creating synchronized LED patterns
* Designing LED animations and visual effects
* Using random number generation
* Applying programming logic to hardware projects
* Understanding how software and hardware work together

These projects provide a solid foundation for understanding LED control and can be expanded into more advanced applications involving displays, sensors, lighting systems, robotics, IoT devices, and interactive embedded systems.
