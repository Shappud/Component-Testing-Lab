# RGB LED Projects

This repository contains a collection of beginner-friendly RGB LED projects created to explore and understand the fundamentals of programming RGB LEDs using an ESP32.

Each project focuses on a different lighting behavior or control technique, helping build a strong foundation in LED control, brightness adjustment, and interactive lighting before moving on to more advanced electronics and embedded systems projects.

These examples demonstrate concepts such as digital output, PWM brightness control, timing with delays, controlling RGB colors, creating lighting sequences, and designing LED patterns. They can also serve as reference implementations that can be reused and expanded in future robotics, IoT, and embedded systems projects.

## Projects Included

### Flashing RGB LED

A basic project that turns an RGB LED on and off repeatedly. This introduces digital output and demonstrates how a microcontroller can control an LED using GPIO pins.

### Fading RGB LED

Uses PWM (Pulse Width Modulation) to smoothly increase and decrease the brightness of an RGB LED. This introduces PWM-based brightness control and demonstrates how digital hardware can be used to create smooth changes in LED brightness.

## Learning Objectives

By completing these projects, you will gain experience with:

* Configuring GPIO pins for RGB LED control
* Writing basic Arduino/ESP32 programs
* Using digital outputs
* Understanding RGB LED color channels
* Controlling LED brightness with PWM
* Creating timed lighting sequences
* Using delays for basic animations
* Creating LED patterns and animations
* Applying programming logic to hardware projects
* Understanding how software and hardware work together

These projects provide a solid foundation for more advanced applications involving displays, sensors, lighting systems, robotics, IoT devices, and interactive embedded systems.
