# Potentiometer Projects

This repository contains a collection of beginner-friendly potentiometer projects created to explore and understand the fundamentals of reading and using potentiometers with an ESP32.

Each project focuses on a different technique for reading analog input, converting potentiometer readings into useful values, controlling outputs, and creating interactive systems. Together, they provide a structured introduction to analog sensors and variable inputs before moving on to more advanced electronics, control systems, and embedded systems projects.

These examples demonstrate concepts such as ADC reading, analog input, value mapping, thresholds, variable control, PWM, and using potentiometers to interact with LEDs, buzzers, motors, and other components. They can also serve as reference implementations that can be reused and expanded in future robotics, IoT, and embedded systems projects.

## Projects Included

### Potentiometer Analog Reader

Reads the potentiometer value using an ESP32 analog input and displays the raw ADC value through the Serial Monitor. This introduces analog input and demonstrates how a microcontroller converts a variable voltage into a numerical reading.

### Potentiometer LED Control

Uses a potentiometer to control the brightness of an LED. This introduces PWM and demonstrates how an analog input can be converted into an output level.

### Potentiometer Threshold

Uses a potentiometer to turn an LED on or off depending on whether the knob is above or below a specific threshold. This introduces conditional logic and demonstrates how analog readings can be used to make decisions.

### Dual Potentiometer Control

Uses two potentiometers to independently control two different outputs. This introduces multiple analog inputs and demonstrates how several variable controls can be processed at the same time.

### Potentiometer RGB LED

Uses 3 potentiometers to control the brightness or color of an RGB LED. This introduces multiple outputs and demonstrates how one analog input can be used to control different output parameters.

## Learning Objectives

By completing these projects, you will gain experience with:

* Reading analog inputs using ESP32 ADC pins
* Understanding how potentiometers work
* Understanding variable resistance and voltage division
* Mapping values between different ranges
* Using thresholds with analog inputs
* Controlling LED brightness
* Using PWM outputs
* Working with RGB LEDs
* Using multiple potentiometers
* Processing multiple analog inputs
* Creating physical control interfaces
* Using variables to store sensor readings
* Applying conditional logic to analog inputs
* Creating reusable potentiometer functions
* Understanding the relationship between input and output
* Applying analog control to robotics and embedded systems

These projects provide a solid foundation for understanding analog inputs and variable controls while demonstrating how potentiometers can be used to interact with different electronic components and systems.
