# Ultrasonic Sensor Projects

This repository contains a collection of beginner-friendly ultrasonic sensor projects created to explore and understand the fundamentals of measuring distance using an ultrasonic sensor with an ESP32.

Each project focuses on a different technique for reading ultrasonic distance measurements, processing sensor data, detecting objects, and using distance information to control outputs. Together, they provide a structured introduction to distance sensing before moving on to more advanced robotics, obstacle detection, automation, and embedded systems projects.

These examples demonstrate concepts such as trigger and echo signals, time-of-flight measurement, distance calculation, thresholds, averaging, object detection, and sensor-based control. They can also serve as reference implementations that can be reused and expanded in future robotics, IoT, and embedded systems projects.

## Projects Included

### Basic Distance Reading

Uses an ultrasonic sensor to measure the distance to an object and displays the result through the Serial Monitor. This introduces the basic operation of ultrasonic sensors and demonstrates how an ESP32 can measure the time taken for an ultrasonic pulse to return.

### Distance in Different Units

Measures an object's distance and displays the result in centimeters, meters, and inches. This introduces unit conversion and demonstrates how the same sensor measurement can be represented in different units.

### Ultrasonic LED Indicator

Controls an LED based on the measured distance. This introduces conditional logic and demonstrates how distance measurements can be used to make decisions and also show visual feedback.

### Object Detection

Detects when an object enters a specified detection range and reports its presence through the Serial Monitor. This introduces object detection and demonstrates how distance sensors can be used as simple proximity sensors.

## Learning Objectives

By completing these projects, you will gain experience with:

* Understanding how ultrasonic sensors measure distance
* Using trigger and echo signals
* Reading ultrasonic sensor measurements with an ESP32
* Measuring time-of-flight
* Calculating distance from travel time
* Converting distance between different units
* Using distance thresholds
* Detecting nearby objects
* Creating proximity detection systems
* Controlling LEDs using sensor readings
* Creating variable visual feedback
* Averaging multiple sensor readings
* Reducing sensor measurement noise
* Processing continuous sensor data
* Creating scanning systems
* Making sensor-based decisions
* Integrating sensors with other electronic components

These projects provide a solid foundation for understanding ultrasonic distance sensing and demonstrate how distance measurements can be transformed into useful information, feedback, and automated actions in robotics, IoT, and embedded systems.
