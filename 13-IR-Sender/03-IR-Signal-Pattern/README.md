# IR Receiver Projects

This repository contains a collection of beginner-friendly IR receiver projects created to explore and understand the fundamentals of receiving infrared signals with an ESP32.

Each project focuses on a different technique for detecting, reading, and processing infrared signals. Together, they provide a structured introduction to IR receivers before moving on to more advanced remote-control and communication projects.

These examples demonstrate concepts such as IR signal detection, remote commands, button input, signal decoding, and reusable functions. They can also serve as reference implementations that can be reused and expanded in future robotics, IoT, and embedded systems projects.

## Projects Included

### IR Signal Detection

Detects incoming infrared signals and displays the received information through the Serial Monitor.

### IR Button Counter

Uses an IR remote button to increase a counter whenever a specific command is received.

### IR Remote Control

Reads commands from an infrared remote and uses them to control an LED.

### IR Command Selector

Uses received IR commands to select between different actions or outputs.

## Learning Objectives

By completing these projects, you will gain experience with:

* Understanding infrared reception
* Receiving IR signals with an ESP32
* Reading IR remote commands
* Decoding infrared signals
* Using remote buttons as inputs
* Processing received commands
* Monitoring IR signals through the Serial Monitor
* Creating actions based on received commands
* Creating reusable IR receiver functions

These projects provide a solid foundation for understanding IR receivers and demonstrate how infrared communication can be used for remote controls, device interfaces, and embedded systems projects.
