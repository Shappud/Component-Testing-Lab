# IR Transmitter Projects

This repository contains a collection of beginner-friendly IR transmitter projects created to explore and understand the fundamentals of sending infrared signals with an ESP32.

Each project focuses on a different technique for transmitting IR signals, controlling commands with buttons, and creating custom infrared signal patterns. Together, they provide a structured introduction to IR transmission before moving on to more advanced remote-control and communication projects.

These examples demonstrate concepts such as IR signal transmission, button input, signal patterns, timing, and reusable functions. They can also serve as reference implementations that can be reused and expanded in future robotics, IoT, and embedded systems projects.

## Projects Included

### IR Signal Transmission

Sends a basic infrared signal using the IR transmitter.

### IR Button Control

Uses push buttons to send different IR commands depending on which button is pressed.

### IR Signal Pattern

Sends custom infrared signal patterns to demonstrate how IR communication works.

## Learning Objectives

By completing these projects, you will gain experience with:

* Understanding infrared transmission
* Sending IR signals with an ESP32
* Creating and transmitting IR commands
* Using push buttons for control
* Creating custom infrared signal patterns
* Working with timing and signal pulses
* Creating reusable IR transmission functions

These projects provide a solid foundation for understanding IR transmitters and demonstrate how infrared communication can be used for remote controls, device interfaces, and embedded systems projects.
