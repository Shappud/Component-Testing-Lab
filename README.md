# ESP32 Component Lab

A collection of ESP32 component tests, experiments, and mini projects created to learn embedded systems, electronics, and robotics through hands-on practice.

This repository focuses on understanding individual electronic components before combining them into larger projects. Each component is documented with source code, wiring, explanations, and observations to serve as both a learning journal and a reference for future projects.

---

## About

The purpose of this repository is to develop a solid understanding of commonly used electronic components and communication protocols used in robotics and embedded systems.

Rather than only showcasing finished projects, this repository documents the process of learning how each component works, how to interface it with the ESP32, and how it can be integrated into real-world applications.

---

## Objectives

- Learn embedded systems through practical experimentation
- Understand GPIO, PWM, ADC, UART, I²C, and SPI communication
- Develop reusable code for future projects
- Improve electronics troubleshooting and debugging skills
- Document the learning process for future reference

## Learning Process

Each component is explored in three stages.

### Basic Test

Learn the fundamental operation of the component.

Examples include blinking an LED, reading a button, or displaying text on a screen.

### Intermediate Test

Explore additional features and improve understanding of the component.

Examples include PWM control, interrupts, communication protocols, and sensor calibration.

### Mini Application

Combine the component with others to create a practical embedded system.

Examples include RFID access control, obstacle detection, line following, digital measurement tools, and automation systems.
